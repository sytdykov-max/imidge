# Post-release 24h Monitoring Protocol

## Owners
- Release owner
- SEO owner
- Checkout owner
- Platform owner

## Monitoring windows
- T+0h, T+1h, T+3h, T+6h, T+12h, T+24h

## Mandatory checks
- Runtime probes
- SEO migration policy
- Checkout synthetic probe
- Error logs and 5xx rates
- Regression trend summary

## Deliverable
`docs/release-handoff-latest.md` updated with 24h health verdict and follow-up actions.
